# Proyecto de ASI
Implementar una arquitectura de red virtualizada segura para el intercambio interno de archivos y administración remota que soporte las operaciones de al menos 3 departamentos de la empresa. Se configurará un servidor central Linux que procesará el 100% de las solicitudes de archivos mediante los protocolos Samba y NFS, permitiendo la administración exclusiva al personal de sistemas vía SSH y SFTP. El sistema deberá estar completamente operativo, documentado y validado mediante pruebas para su entrega definitiva a más tardar el 20 de noviembre de 2026.
## Entregables principales
1. Tres máquinas virtuales configuradas (servidor Debian, cliente Windows, cliente Ubuntu Linux).
2. Manual Técnico.
3. Manual de usuario.
4. Video demostrativo funcional.
5.Los servicios Samba y NFS completamente configurados y operando en el servidor.
6. Los servicios SSH y SFTP están habilitados.
